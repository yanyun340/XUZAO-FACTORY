| 用例 | 验证点 |
| --- | --- |
| 未开启时任意设备可登录 | `deviceBindingMode=OFF` 不影响登录，会话 `deviceId` 为 null |

| 批准后同设备成功 | 会话写入 `deviceId`，`/auth/me` 可用 |
| 第二台设备仍待批准 | 同账号已有一台 ACTIVE 不会放行另一台 |
| 吊销即踢下线 | 该设备会话全部失效，重登仍 403（不自动复活） |
| 删最后一台自动关闭受控 | `bindingDisabled=true`，账号恢复任意设备登录 |
| 设备标识格式非法 | 400 `DEVICE_KEY_INVALID` |
| 现场角色不能管理设备 | 403 |

## 5. 边界说明

这是**弱设备绑定**：`deviceKey` 由浏览器生成并保存在 localStorage，清浏览器数据或手工复制都能绕过。服务端用它做“审批 + 审计 + 踢下线”，不宣称硬件级防伪造；状态表与文档按同一口径描述。
