# ADR-0001：内嵌 PostgreSQL 与逻辑备份

状态：已采纳｜日期：2026-11-04｜决策人：开发者

## 背景

考核要求“干净环境启动、真实数据库、迁移”，同时要求把数据库和附件实际恢复到新的隔离环境。验收机器不一定预装 PostgreSQL，也不保证有管理员权限；Windows 中文路径还会让 `initdb` 失败。

## 决策

1. 使用 `embedded-postgres` 18.6 作为开发/验收数据库，默认端口 55432。
2. 首次启动把二进制复制到 `%USERPROFILE%\.xuzao\pgsql`，数据目录放在 `%USERPROFILE%\.xuzao\pgdata`，绕开中文路径。
3. 备份不用 `pg_dump`（发行版未提供），改为 Node 逐表导出 JSON + 同名 `.assets` 附件目录 + 全局 SHA-256。
4. 恢复脚本强制执行隔离护栏：库名/附件目录需含 `restore|verify|test`，且不能等于当前连接串或 `UPLOAD_DIR`。

## 后果

- 优点：`npm install && npm run dev` 即可复现；不污染系统安装；备份可被人读懂。
- 代价：首次复制约 108MB；逻辑备份在数据量大时比物理备份慢；恢复按外键顺序串行写入。
- 约束：备份文件含业务与附件内容，按敏感数据处理；不得提交仓库。

## 备选方案

| 方案 | 未采用原因 |
| --- | --- |
| 要求本机安装 PostgreSQL | 干净环境不可复现，中文路径风险 |
| Docker Compose | 验收机不保证有 Docker |
| `pg_dump` 物理备份 | 内嵌发行版不含该工具 |
