# 功能状态表（R01–R27）

版本：0.1.0｜更新：2026-11-04
口径：`M` 为最低实现；`F` 为可选加分项。状态只写**当前代码实际做到的事**，未选做直接写“未选做”，不把 M 降级为加分项。

状态含义：
- **已验收**：代码存在，且当前版本有可复现的执行结果（`tests/reports/`）。
- **已实现**：代码存在，但只有手工冒烟或部分验证。
- **进行中**：本次交付尚未完成。
- **未选做**：明确不在本次范围。
