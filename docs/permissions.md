# 角色与权限

版本：0.2.0｜实现：`backend/src/auth/guards.ts`、`backend/src/domain/orders.ts`、各路由守卫
更新时间：2026-11-04

权限分为三层：**能不能登录**、**能不能调用接口**、**能不能看到字段**。三层都在后端执行，前端隐藏按钮只是体验优化，不构成安全边界。

## 1. 角色定义

| 角色 | 中文 | 部门绑定 | 典型使用者 |
| --- | --- | --- | --- |
| `ADMIN` | 管理员 | 可选 | 业务负责人：下单、采购、下发、决策、主数据、审计 |
| `LOGISTICS` | 物流 | 可选 | 到货登记、发货登记 |
| `PRODUCTION` | 生产 | **必需**（category=PRODUCTION） | 查看本部门任务、提交生产反馈 |
| `QC` | 品控 | 可选 | 质检录入 |
| `PACKING` | 包装 | 可选 | 包装登记 |

账号由管理员创建；停用、改角色、重置密码都会撤销该用户全部现有会话（R01F）。

拒绝规则：

- 未登录 → 401 `NOT_LOGGED_IN`；会话失效 → 401 `SESSION_EXPIRED`。
- 角色不符 → 403 `FORBIDDEN`。
- 生产反馈还会校验“操作者部门 = 生产任务部门”，不符则 403；生产下发会校验目标部门 `category=PRODUCTION` 且员工属于该部门。

## 3. 字段级脱敏

| 字段 | 可见范围 | 实现 |
| --- | --- | --- |
| 订单金额（`unitPrice`、`profit`、看板利润） | 仅 ADMIN | `canSeeMoney(role)`；非管理员 `flow.profit = null`，订单明细单价不返回 |
| 客户联系人 / 电话 | ADMIN、LOGISTICS | 其他角色 DTO 中为 `null` |
| 生产计件单价 | ADMIN；或任务勾选 `unitPriceVisible`；或本部门 `department.unitPriceVisible=true` 且任务属于该部门 | 非管理员返回 `unitPriceForWorker`，不返回总成本；部门开关不跨部门生效 |
| 看板利润 | 仅 ADMIN | 非管理员 `profit = null`，连金额字段都不返回 |
| 用户 `passwordHash`、`tokenHash` | 任何角色均不可见 | 查询不选该字段 |
| 审计 `before/after` 中的敏感字段 | 不写入密码、token | 审计写入时过滤 |

前端配套：`OrderDetailPage` 根据 `flow.profit === null` 隐藏利润区块；`FlowPanel` 只渲染后端返回的 `allowedActions`。

## 4. 数据范围

- 订单、生产任务、质检记录对全部登录角色可见（车间协作需要看到上下游上下文），但金额和客户联系方式按上表脱敏。
- 通知只返回 `recipientId = 当前用户` 的记录；标记已读同样校验归属，不能操作他人的通知。
- 附件上传要求登录；下载同样要求登录，不提供匿名链接。
- 生产反馈是唯一“同角色 + 同部门”双条件校验的写操作。

## 5. 会话与撤销

| 操作 | 效果 |
| --- | --- |
| 登录 | 新建会话，写入 `sessions`，返回 HttpOnly Cookie |
| 登出 | 撤销当前会话并清 Cookie |
| 改密码（本人或管理员重置） | `sessionVersion + 1`，批量撤销该用户全部会话 |
| 改角色 / 停用账号 | 同上；被停用账号立即无法登录 |
| 手动“撤销全部会话” | 管理员对该用户执行，批量写 `revokedAt` |

请求时的校验顺序：Cookie → `tokenHash` 查会话 → 未过期 → 未撤销 → 用户启用 → `sessionVersion` 与签发时一致。任一失败都返回 401，不继续执行业务。
